First-time setup and how this works
  1. Push this project to your GitHub repository. GitHub Actions builds the LTX service image from the included Dockerfile and publishes it to GitHub Container Registry.
  2. In RunPod, create a Pod from that image. Attach a persistent volume at /workspace, set HF_TOKEN and LTX_SERVICE_TOKEN, and expose HTTP port 8000.
  3. The Pod installs the LTX Python dependencies in its container and downloads the gated LTX-2.5 weights to its persistent RunPod volume on first start. No model weights are downloaded to this computer.
  4. Paste your RunPod API key and service token above, find the Pod, test the connection, and generate.
